Regras gerais do layout

Orientações que devem ser seguidas em todas as novas páginas.

Estrutura
  • Reutilizar sidebar, topbar e footer.
  • Usar .page-content na área principal.
  • Centralizar conteúdo com .content-container.
  • Utilizar .panel para blocos principais.
CSS
  • Evitar CSS inline.
  • Reutilizar classes do app.css.
  • Utilizar Grid e Flexbox.
  • Sempre testar desktop, tablet e mobile.

Estrutura recomendada no Thymeleaf

As páginas reais devem reutilizar os fragments existentes. 

<body>

<div class="app-layout">

    <div th:replace="~{fragments/sidebar :: sidebar}"></div>

    <div class="main-area">

        <div th:replace="~{fragments/topbar :: topbar}"></div>

        <main class="page-content">

            <div class="content-container">

                Conteúdo da página

            </div>

        </main>

        <div th:replace="~{fragments/footer :: footer}"></div>

    </div>

</div>

</body>
